# LaserX Beta Feedback

Use one report per problem. Do not include API keys, full private prompts,
customer artwork, or proprietary project files unless the owner explicitly
approves a secure sharing path.

## Required report

- LaserX version and installer filename;
- Windows edition/version, x64 architecture, display resolution, and scale;
- exact workflow and numbered reproduction steps;
- expected result and actual result;
- whether project geometry, the last explicit save, export files, or recovery
  data changed;
- whether restart reproduces or recovers the problem;
- smallest non-sensitive fixture that reproduces it;
- relevant warning/error text with secrets and customer data removed;
- severity: data loss/manufacturing correctness, workflow blocker, severe
  usability/accessibility, or minor defect.

## Manufacturing reports

Always include display units, stock dimensions/thickness designation, source
file units, expected exported bounds, measured downstream bounds, and the CAM
inspector used. Do not claim a file is safe merely because LaserX analysis
completed.

## Installer reports

Record whether the case was fresh install, upgrade, or uninstall; whether the
desktop shortcut was selected; whether user data was preserved or explicitly
removed; installer signature/publisher status; and the exact failure stage.
