# M23 — Version 1.0 Release and Broader-Market Launch

## User-visible outcome

LaserX ships as a signed, supported, documented, premium-feeling Version 1.0 product that users across flat-cut maker markets can install, trial, purchase, learn, trust, and use with their existing downstream software.

## Activation gate

M23 remains blocked until M22 is complete, the owner approves the Version 1 feature boundary, pricing, trial, support commitment, signing/publication plan, launch positioning, and release candidate.

## Included

- final Version 1 scope freeze and release-candidate defect policy;
- trusted Windows signing or separately accepted managed-signing design;
- exact-source provenance, checksums, semantic version, release notes, changelog, known issues, privacy, terms, support, recovery, and troubleshooting;
- download/purchase/trial experience consistent with M20;
- final clean install, upgrade, migration, recovery, uninstall, and rollback validation;
- representative deterministic sign, import, tracing, optional-AI, material, process-guidance, 3D, export-profile, and downstream-software workflows;
- final performance, accessibility, high-DPI, security, dependency, license, and data-integrity gates;
- launch messaging based on Issue #44: premium product, generous price, machine-independent, deterministic core, optional AI, truthful 3D, and downstream companionship;
- grassroots launch materials supported by real beta evidence and user-created work;
- no unsupported machine-control or proprietary-format claim.

## Acceptance tests

1. A clean supported Windows machine can install, trial, purchase/activate, complete the primary workflow, upgrade, recover, and uninstall.
2. The final release candidate passes every prior milestone regression on the exact reviewed head.
3. Real-user evidence supports the ten-minute first-session target or any remaining limitation is explicitly accepted and published.
4. Representative SVG/DXF and production packages open at intended scale in reviewed downstream software.
5. Physical 3D remains deterministic, non-mutating, lazy-loaded, and safely degradable.
6. Optional AI remains optional, secure, user-supplied, and non-blocking.
7. Licensing never destroys projects or blocks access to existing files without clear policy.
8. Signed artifacts, provenance, hashes, version, and source commit are recorded.
9. Release notes, known issues, privacy, terms, support, and recovery documents are complete.
10. No severity-1 security, data-loss, manufacturing-correctness, accessibility, or license issue remains unresolved.
11. Version 1.0 is tagged and published only after ChatGPT exact-head audit and explicit owner advancement.

## Exit checklist

- [ ] Version 1 scope freeze is recorded.
- [ ] Final release candidate is independently audited.
- [ ] Trusted signing/publication and rollback pass.
- [ ] Real-user, downstream-software, accessibility, performance, security, migration, and recovery evidence pass.
- [ ] Pricing, trial, purchase, support, and launch materials are approved.
- [ ] Signed Version 1.0 artifacts, provenance, and checksums are published.
- [ ] Version 1.0 tag is created only after owner command.
- [ ] Machine-platform work remains blocked until a separate explicit M24 activation.

## Explicitly excluded

No machine control, controller firmware, general-purpose CAD, native DWG, cloud collaboration, marketplace, broad nesting, quoting, or unrelated post-Version-1 expansion belongs in M23.
