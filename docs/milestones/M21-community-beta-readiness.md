# M21 — Community Beta Distribution Readiness

## User-visible outcome

Invited users from real maker and fabrication communities can install LaserX, understand what it is, complete a project, report problems, and share useful evidence through a controlled beta process.

## Activation gate

M21 remains blocked until M20 is complete and the owner explicitly approves the beta cohort, distribution model, signing/publication boundary, support capacity, and feedback terms.

## Included

- controlled beta cohort and supported Windows matrix;
- installer, upgrade, recovery, uninstall, and rollback instructions;
- clear positioning: LaserX creates the product; downstream software manufactures it;
- first-run onboarding, sample projects, Inkscape companion guidance, LightBurn/plasma/router/waterjet handoff guidance;
- privacy and optional-AI credential explanations;
- beta terms, support channel, known issues, crash/error evidence instructions, and reproducible bug template;
- in-app feedback entry that does not silently upload projects or private content;
- owner-approved diagnostic package with user review before sharing;
- cohort tracking without invasive analytics;
- community outreach kit for Inkscape, LightBurn, plasma, laser, router, woodworking, acrylic, Etsy-maker, makerspace, and school communities;
- explicit decision on trusted signing and public distribution before software leaves the owner-controlled private group.

## Acceptance tests

1. A clean outside machine can install, launch, onboard, complete a project, export, and uninstall using only published beta instructions.
2. Users understand that LaserX is design/preparation software rather than machine control.
3. Users understand AI is optional and user-supplied.
4. Feedback flow captures version, reproduction, expected/actual behavior, and optional user-reviewed diagnostics.
5. No project, prompt, API key, or private customer file is uploaded without explicit review and consent.
6. Known issues, recovery, support, and update instructions are clear.
7. Beta distribution cannot accidentally publish an unreviewed artifact.
8. Signing/publication behavior matches the owner-approved boundary.
9. Sample projects and export guides cover at least Inkscape, general laser/LightBurn, and plasma CAM workflows.

## Exit checklist

- [ ] Cohort, support, feedback, privacy, and distribution decisions are recorded.
- [ ] Beta installer and documentation pass on clean outside machines.
- [ ] Outreach and feedback materials are approved.
- [ ] Controlled artifact publication and rollback are verified.
- [ ] First beta cohort is invited only after exact-head audit and owner approval.
- [ ] Status advances to M22 only after beta-readiness issue closure and owner approval.

## Explicitly excluded

No broad public launch, unsupported-platform promise, permanent free-access promise, invasive analytics, cloud project sync, or machine-control claim belongs in M21.
