# LaserX Design Studio 0.13.0-beta.1

This is the first controlled installable beta candidate, not Version 1.0.

## Highlights

- assisted signed x64 Windows installer with Start Menu integration and an
  explicit desktop-shortcut choice;
- upgrade continuity and clean uninstall with preserve-by-default user data;
- application data, encrypted credentials, recovery, logs, caches, and local
  crash dumps isolated under the Windows per-user application-data root;
- bounded emergency recovery that preserves the last explicit save;
- exact signed-artifact hashes and source/signing provenance;
- complete text, vector, raster, cutability, sign-template, AI-concept, layered
  production, and M13 hands-on repair workflows from the prior reviewed gates.

## Before installing

Review `docs/KNOWN_ISSUES.md`. Keep original customer files and downstream CAM
validation. LaserX manufacturing analysis is advisory and does not replace
operator judgment, machine setup, or physical test cuts.

## Upgrade and uninstall

Install this beta over an earlier LaserX beta to preserve application data.
Uninstall preserves projects, settings, credentials, and recovery by default.
Select the separate remove-user-data choice only when those local records are
no longer needed.
