# Architecture Decision Records

ADRs capture decisions that are expensive to reverse or affect multiple packages. Use sequential four-digit numbers, state the status, decision, rationale, alternatives, and consequences. Research notes do not become decisions until accepted here.

Accepted implementation decisions:

- ADR 0005 — M01 toolchain and renderer state
- ADR 0006 — secure Electron boundary
- ADR 0007 — project schema v1, atomic saves, and recovery
- ADR 0008 — canonical document and viewport boundary
- ADR 0009 — project schema v2 migration
