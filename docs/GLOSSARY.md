# Glossary

- **Bridge:** Material intentionally left connecting an enclosed region so it does not fall out.
- **Cutability:** Analysis of whether geometry satisfies configured process constraints.
- **Drop-out:** Region expected to separate from retained material during cutting.
- **Island:** Disconnected retained geometry that may need a bridge or backing layer.
- **Kerf:** Width of material removed by the cutting process.
- **Native project:** Editable `.laserx` document, not a manufacturing export.
- **Normalization:** Converting imported/generated geometry into consistent domain representation.
- **Retained metal:** Region intended to remain in the finished face layer.
- **Tracing:** Converting raster pixels into vector paths.
- **Topology-changing operation:** Any operation that can create, remove, split, or merge contours.
