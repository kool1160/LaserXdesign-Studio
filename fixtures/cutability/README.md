# M08 cutability fixtures

`m08-rule-goldens.json` is repository-owned geometry evidence for the M08 rule
suite. It covers nested retained/drop-out classification, the conservative
ambiguous result for open geometry, a false-positive guard for a safe single
cutout, and narrow/close geometry that crosses explicit settings.

Coordinates and limits are millimeters. The fixtures use geometric containment
only; no character or font names participate in classification.
