# M12 production package goldens

`m12-package-goldens.json` pins independently inspectable two- and three-layer
package filenames, physical roles, exact millimeter origin/stock, and shared
explicitly designated registration-hole coordinates. Decorative ellipses are
present in the representative layers but excluded from registration evidence.
The production-export tests derive the same summary from real SVG/DXF artifacts
and the generated manifest.
